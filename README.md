# STÆ302G practice room

Q1 and Q2 practice for Mathematical Analysis III (Stærðfræðigreining III).

Visit https://greiningiii.github.io/ for random practice sets, automatic
feedback, and worked answers in English and Icelandic. Switch languages without losing
your current set. Answers and progress stay in your browser;
nothing is submitted to Canvas.

This is a static HTML, CSS, and JavaScript site. To preview locally, run
`python -m http.server 8000` and open http://localhost:8000/.

KaTeX and mathjs are bundled locally; their licenses are in `vendor/`.
